# コピーしたファイルを読み取り専用で照合する

Python 3.9以上、標準ライブラリのみ。スクリプトはファイルを変更・削除しません。
sample-original.txtとsample-copy.txtは独自に作成した同じ短い練習用テキストです。撮影素材ではありません。

ZIPを展開したhash-practiceフォルダーで実行します。

```sh
python3 --version
python3 compare_files.py sample-original.txt sample-copy.txt
```

最後にPASSと表示され、終了コードが0なら、この2ファイルはSHA-256とバイト数が一致しています。
DIFFERENTは不一致で終了コード1、ERRORは存在しないパス・同じファイル・読取り失敗などで終了コード2です。
同じファイルへのハードリンクやシンボリックリンクを2つ指定した場合も比較を拒否します。

自分の素材ではコピーを先に完了し、コピー元とコピー先を別のパスで指定します。空白を含むパスは引用符で囲みます。

```sh
python3 compare_files.py "/Volumes/CARD/DCIM/clip.mp4" "/Volumes/WORK/footage/clip.mp4"
```

このコマンドは配置例です。実在する自分のパスへ置き換えてください。
実行中に素材を書き換えないでください。容量・更新日時・ファイルの識別情報が読取り前後で変わればERRORになりますが、あらゆる同時変更を保証して検出する機能ではありません。

1組の一致は、カード全体のコピー完了、正常な映像・音声の再生、別媒体へのバックアップ、将来の読取り成功を証明しません。
フォルダー全体の列挙、クラウドの未ダウンロード素材、カード消去は扱いません。この手順にカードの初期化や削除を含めないでください。

一次資料: [Python hashlib](https://docs.python.org/3/library/hashlib.html)
