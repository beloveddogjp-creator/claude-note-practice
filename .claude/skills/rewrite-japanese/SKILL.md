# 日本語の下書きを推敲する

1. draft.md を読み、元の主張、数値、期間、不確かな表現を確認する。
2. 内容を増やさず、文のつながり、語順、段落を読みやすくする。
3. 書かれていない体験や、根拠のない効果を加えない。
4. 元の draft.md は変更せず、推敲文を edited.md に保存する。
5. 元と推敲後を比較し、数値と断定の強さが変わっていないか確認する。
6. 変更点と未確認の点を、日本語で短く報告する。

調査や新規企画を頼まれた場合は、この手順の対象外として扱う。
